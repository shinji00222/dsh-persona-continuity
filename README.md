# 人格续忆 · DSH Persona Continuity

在 DeepSeek Harness 新建会话时选择一个人格。每个人格有独立的长期记忆，聊天后自动提炼并保存。

1. 在新会话输入框旁点「普通会话」，再点菜单里的「＋ 新建人格」。输入名称后点「创建并使用」，就能直接用这个人格聊天。
2. 左键选择人格，右键人格条目可重命名。新会话默认是「普通会话」。人格设定可在「设置 → 人格续忆」里填写。
3. 聊到偏好、决定、进度或经验后，后台复用当前模型提炼。从「设置 → 人格续忆」可以查看、修改、删除记忆。
4. 宿主为相关问题预先选出少量笔记及详情。「继续上次」会从同人格最近一个有记忆的其他会话取资料。

## 本地试用

打包运行 `npm pack`。将生成的 `dsh-persona-continuity-0.2.0-preview.2.tgz` 装入测试 profile，再启动该 profile。已在 DSH 0.2.2-rc.3 宿主验证。

- SQLite 文件位于 `$DSH_HOME/persona-continuity/memory.sqlite`。提炼时会将该轮的有限正文发送给当前会话的模型，召回时会把选中的记忆内容提供给模型。
- 最新提炼可能需要几十秒。被取消和未完整结束的轮次跳过提炼。已开始的会话沿用绑定的人格设定版本。
- 从人工确认预览版升级时，已确认条目继续参与召回，原候选保存在数据库的历史表。
- 记忆索引按关键词查询，首版最多检索同人格最近 1000 条。会话来源用 ID 和轮次表示。
- 实现和调研参考见 [调研](docs/research.md)，阶段与验收见 [规划](docs/project-plan.md)。

开发验证使用 `npm run check` 和 `npm test`。
