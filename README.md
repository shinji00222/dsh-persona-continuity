# 人格续忆 · DSH Persona Continuity

在 DeepSeek Harness 新建会话时选择一个人格。每个人格会在后台积累自己的长期记忆。下次选回这个人格，可以直接说「继续上次」。

1. 在设置的「人格续忆」里创建两个人格，分别填名称和设定。
2. 在新会话输入框旁选择人格，再发送首条消息。新会话默认是「普通会话」。
3. 聊到偏好、决定、进度或经验后，后台复用当前模型提炼并自动保存。在设置里选人格，可以搜索、展开和删除记忆。
4. 新会话自动获得少量近期记忆摘要。需要细节时，模型可按主题搜索索引，或按条目 ID 查看细节及来源会话。

## 本地试用

打包运行 `npm pack`。使用 DSH 插件管理器将生成的 `dsh-persona-continuity-0.1.0.tgz` 装入测试 profile，再启动该 profile。使用带 Web 客户端、支持 Node SQLite 的 DSH 0.2.x 宿主。首次先试两个不同人格和一个普通会话。

- SQLite 文件位于 `$DSH_HOME/persona-continuity/memory.sqlite`。提炼时会将该轮的有限正文发送给当前会话的模型，召回时会把选中的记忆内容提供给模型。
- 首版的模型记忆按主题存储。最新提炼可能需要几十秒。被取消和未完整结束的轮次不入库。已开始的会话沿用原人格。
- 记忆索引按关键词查询，首版最多检索同人格最近 1000 条。会话来源用 ID 和轮次表示。
- 实现和调研参考见 [调研](docs/research.md)，阶段与验收见 [规划](docs/project-plan.md)。

开发验证使用 `npm run check` 和 `npm test`。
