# 人格续忆 · DSH Persona Continuity

在 DeepSeek Harness 新建会话时选择一个人格。每个人格有独立的长期记忆，批准后可在同一人格的其他会话中使用。

1. 在新会话输入框旁点「普通会话」，再点菜单里的「＋ 新建人格」。输入名称后点「创建并使用」，就能直接用这个人格聊天。
2. 用旁边的人格菜单切换已有的人格。新会话默认是「普通会话」。人格设定可稍后在「设置 → 人格续忆」里填写。
3. 聊到偏好、决定、进度或经验后，后台复用当前模型提炼候选。在「设置 → 人格续忆」选中人格，可批准、编辑后批准或拒绝，也可修改、删除已保存的记忆。
4. 相关问题会带上少量已确认摘要。「继续上次」会优先带上当前工作区的近期条目。模型可按主题搜索索引，或按条目 ID 查看细节及来源会话 ID 和轮次。

## 本地试用

打包运行 `npm pack`。将生成的 `dsh-persona-continuity-0.2.0-preview.1.tgz` 装入测试 profile，再启动该 profile。已在 DSH 0.2.2-rc.3 宿主验证。

- SQLite 文件位于 `$DSH_HOME/persona-continuity/memory.sqlite`。提炼时会将该轮的有限正文发送给当前会话的模型，召回时会把选中的记忆内容提供给模型。
- 最新提炼可能需要几十秒。被取消和未完整结束的轮次跳过提炼。已开始的会话沿用绑定的人格设定版本。
- 从 0.1.x 升级时，自动保存的旧条目会带来源进入待确认列表。升级前保留数据库备份，回退到 0.1.x 时需同时恢复旧库。
- 记忆索引按关键词查询，首版最多检索同人格最近 1000 条。会话来源用 ID 和轮次表示。
- 实现和调研参考见 [调研](docs/research.md)，阶段与验收见 [规划](docs/project-plan.md)。

开发验证使用 `npm run check` 和 `npm test`。
