# DSH 模拟任务 · 实现规划

基线 `dsh-persona-continuity` 0.2.0-preview.13。实现落在现有插件的「模拟任务」页，校准入口放角色库。SimWorld 仅作源码参考。先跑问卷闭环，再扩展访谈和协作。演示覆盖医患和一个非医疗场景。[技术调研](simulation-research.md)

## 对象和边界

| 对象 | 实现 |
| --- | --- |
| 角色库 | 从 CSV / JSON 批量导入稳定角色 ID、分组、背景。角色版本引用已版本化的案例资料，可选带入既往任务记忆。与日常对话人格隔离。 |
| 任务 | 问卷版本含公共材料、受访组、题目 ID、选项 ID。首版单选和开放题。点击运行时固定角色、案例、可见记忆、任务及模型/提示词版本。A/B 共用起始角色快照，追访显式选取上次经历。 |
| 运行 | DSH 模型每角色请求一次完整答卷；输入仅含角色自身资料和任务材料。SQLite 限并发队列，以 `runId + roleId` 去重。校验 JSON 和选项，保存有效答案、缺答和失败，重启可续跑，失败项可单独重试。 |
| 真人答卷 | 角色库的校准页接受手填、CSV / JSON 和外部适配器。支持匿名逐人答卷、分组汇总。先映射和预览再入库。外部适配器负责授权、分页和映射；首版接测试端点。 |

## 校准契约

- 对齐键 `questionnaireVersion + materialVersion + questionId + groupId + optionId`。导入批次保留来源、批次版本、有效人数与缺答人数；平台适配器还返回源游标。
- 给每个选项显示真人比例、模拟比例、带符号百分点差。各侧用本侧有效人数作分母。开放题保留正文，首版用人工主题标签比较。无法对齐时显示缺数据，无可比真人批次时标记「未校准」。
- 先用调整批次定位偏差，用户更新角色/案例或任务提示词，保存新版本并重跑。复测使用留出真人批次；无留出数据时展示描述性差异。报告记录运行 ID、角色库版本、任务版本和真人批次 ID。模拟输入禁止包含校准答卷、比例或标签。
- 复用现有 DSH 模型调用和 SQLite 租约机制。新增模拟专用表和持久失败状态。问卷快照固定实际输入即可。

## 顺序与验收

1. **角色库与任务**。用记录型模型检查不同角色的输入隔离和输入版本。
2. **执行与恢复**。跑 100 角色。覆盖限并发、错误输出、单项重试、重启续跑、答卷去重、运行中编辑不影响当前快照、同一角色在下一任务找回上次经历。
3. **校准闭环**。手填、文件和测试 API 导入同一批数据，报告一致。真人 18/30、模拟 27/30 显示 +30 个百分点。用独立验证批次检查调整前后，检查真人答卷未进入模型请求。
4. **桌面验收**。在隔离 DSH profile 用医患及非医疗案例跑全链路，再用真实模型验证答卷和追访。回归普通会话和现有人格记忆。真实平台与真人数据的效果另行验收。
