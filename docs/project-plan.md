# DSH 人格续忆项目规划

项目包名 `dsh-persona-continuity`，人工确认预览版 0.2.0-preview.1。来源和方案核对见 [调研](research.md)。

## 首版体验

新会话默认是 DSH 普通会话，也可以在发送首条消息前选一个自己创建的人格。会话记住所选人格，两个同时打开的会话可以使用不同人格。各人格以稳定 ID 持有独立的长期记忆，改名仍沿用原记忆。

人格会话的成功轮次结束后，后台复用当前模型提炼有长期价值的偏好、决定、进度、经验和事实。每个人格在设置中有独立的待确认列表，用户可以批准、编辑后批准或拒绝。确认后的条目可编辑和删除。

同一人格的相关请求收到少量带 ID 的已确认摘要。「继续上次」会优先呈现当前工作区的近期条目。模型可以用 `persona_continuity_lookup` 搜索该人格的确认索引，再按 ID 查询详情、来源会话 ID 和轮次。普通会话、子会话和本机无痕插件格式的会话跳过这条记忆路径。

## 实现边界

- Cordis 插件负责在首条模型请求前安装人格设定、记忆摘要和只读索引工具。设置页与输入框界面通过 DSH 插槽接入。
- SQLite 保存人格、会话绑定、待确认候选、长期记忆和后台任务。提炼任务以会话和轮次标识，可在宿主重启后继续处理。修订候选批准时才替换同人格、类别、主题和工作区的已确认条目。
- 摘要优先显示当前工作区的近期条目，检索使用中文词片段、英文词和符号附近的编号。设置里的索引详情显示来源 ID 和轮次。
- 提炼失败按限定次数重试。检索和注入有数量上限。跨设备同步、语义检索和中途换人格留待后续。

## 各阶段目标

| 阶段 | 目标 | 验收 |
| --- | --- | --- |
| 0 · 接入验证 | 在隔离 profile 验证宿主、客户端资源、会话事件、工具和存储。 | 可在目标版本 Web 宿主注册插件，并通过浏览器访问设置和选择器。 |
| 1 · 人格与召回 | 支持创建、改名、选择和恢复人格，接上短摘要和详细索引。 | 两个并行会话的人格不同，普通会话保持原行为。重启后选回人格，首请求只获取该人格的摘要。 |
| 2 · 提炼与确认 | 成功轮次在后台提炼并等待用户审核。 | 待确认内容无法召回。批准后相关请求召回用户确认的正文，拒绝及删除后无法召回。验证重复批准和重启恢复。 |
| 3 · 试用包 | 打包，写试用说明，用桌面和真实模型测「继续上次」。 | 隔离验证通过后，再使用真实模型检查摘要是否能带来正确接续，并录下试用过程。 |
| 4 · 迭代 | 收集误召回、漏召回和成本问题。 | 用真实失败样本对照首版，在人格隔离和上下文预算下验证改进。 |

用记录型假模型验证实际请求和索引归属，用真实模型另行验证自然接续效果。
